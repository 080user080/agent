# ❓ FAQ (Часті питання)

## Загальні питання

### Q: Як встановити агент?
**A:**
```bash
git clone https://github.com/080user080/agent.git
cd agent
pip install -r requirements.txt
python run.py --qt  # PyQt6 (рекомендовано)
```

### Q: Які вимоги до системи?
**A:**
- Python 3.10+
- Windows 10/11
- LM Studio (локальні LLM) або OpenAI API key
- 8GB+ RAM (рекомендується 16GB для локальних LLM)

### Q: Чи працює на Linux/Mac?
**A:** Частково. GUI (Tkinter/PyQt6) працює, але:
- Глобальний голосовий вхід (hotkey) — тільки Windows
- Деякі системні команди можуть не працювати

## Налаштування

### Q: Як налаштувати LLM ендпоінт?
**A:**
1. Запустіть агента
2. Перейдіть у вкладку "Налаштування"
3. В розділі "LLM" додайте ендпоінт:
   - **LM Studio**: `http://localhost:1234/v1`
   - **OpenAI**: `https://api.openai.com/v1`
   - **Groq**: `https://api.groq.com/openai/v1`
4. Введіть API key (якщо потрібно)
5. Натисніть "Test" для перевірки

### Q: Як змінити hotkey для голосового вводу?
**A:**
1. Відкрийте налаштування
2. Знайдіть `GLOBAL_VOICE_HOTKEY`
3. Змініть значення (наприклад, `win+v`)
4. Перезавантажте агента

### Q: Як увімкнути/вимкнути STT/TTS?
**A:**
- **STT**: Налаштування → `STT_ENABLED` (True/False)
- **TTS**: Налаштування → `TTS_ENABLED` (True/False)

## Проблеми

### Q: LLM не відповідає
**A:**
1. Перевірте з'єднання з ендпоінтом (кнопка "Test")
2. Перевірте API key
3. Перевірте, чи запущений LM Studio (якщо використовуєте локальний LLM)
4. Дивіться логи у вкладці "Логи"

### Q: Голосовий ввід не працює
**A:**
1. Перевірте, чи `STT_ENABLED=True`
2. Перевірте мікрофон (налаштування Windows)
3. Спробуйте інший hotkey
4. Дивіться логи у вкладці "Логи"

### Q: TTS не озвучує відповіді
**A:**
1. Перевірте, чи `TTS_ENABLED=True`
2. Перевірте налаштування голосу (голос, швидкість, гучність)
3. Перевірте, чи не призупинено запис під час озвучення

### Q: GUI не відкривається
**A:**
1. Перевірте, чи встановлено PyQt6/Tkinter
2. Спробуйте інший backend: `python run.py --tk` або `python run.py --qt`
3. Дивіться помилки в консолі

### Q: AgentLoop застряг в циклі
**A:**
1. Натисніть "⬛ Стоп"
2. Якщо не допомагає — закрийте GUI через диспетчер задач
3. Зменшіть `max_steps` в налаштуваннях AgentLoop

## Безпека

### Q: Чи безпечно виконувати код через агента?
**A:** Код виконується в сендбоксі (`core_safety_sandbox.py`), але:
- Не давайте агенту доступ до чутливих даних
- Перевіряйте плани перед виконанням
- Використовуйте venv для ізоляції

### Q: Чи агент відправляє дані на сервери?
**A:** Тільки:
- LLM запити до налаштованих ендпоінтів
- TTS запити до edge-tts (Microsoft)
- STT запити до локальних моделей

### Q: Де зберігаються API keys?
**A:** В налаштуваннях GUI (plain text). Не коміть їх в репозиторій!

## Розробка

### Q: Як додати новий модуль `aaa_*`?
**A:**
1. Створіть файл `functions/aaa_new_module.py`
2. Реалізуйте функцію з docstring
3. Зареєструйте в `FunctionRegistry` (див. `logic_core.py`)
4. Додайте тести в `tests/test_aaa_new_module.py`
5. Оновіть `docs/MODULES.md`

### Q: Як запустити тести?
**A:**
```bash
# Всі тести
python -m pytest tests/ -v

# Конкретний тест
python -m pytest tests/test_aaa_create_file.py -v

# З покриттям
coverage run -m pytest tests/
coverage report
```

### Q: Як змінити GUI?
**A:**
- **PyQt6**: `core_gui_pyqt6/main_window.py`
- **Вкладки**: `gui_tabs/*.py`
